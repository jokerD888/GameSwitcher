# GameSwitcher — 游戏与办公应用切换工具

Windows 托盘工具：保存应用启动记录，正常关闭非基线、非排除的可见应用，游戏结束后尝试重新打开。

## 稳定性修复后的行为

- **先保存，后关闭**：恢复记录原子写入成功后才发送关闭请求；失败就停止操作。
- **正常关闭**：默认等待 5 秒。保存提示、取消关闭或权限受限的应用会保留；不会自动强杀，也不会结束进程树。
- **明确的处理范围**：只处理当前用户、当前登录会话中识别到的可见窗口。保护系统程序、自身及祖先进程；按完整路径识别程序。
- **恢复有确认**：保留每个独立窗口进程的启动参数和工作目录。观察到稳定的新窗口后才清除对应记录；未确认项继续保留。
- **避免重复启动**：未确认的启动请求不会因再次点击“恢复”被自动重复提交。确认程序未打开后，可以使用“重新尝试未确认启动”。
- **安全退出**：退出会取消后续操作并等待正在执行的任务收尾，最后释放单实例锁。
- **排除列表可刷新**：点击“刷新运行应用列表”后获取新软件；没有前 15 项限制。通过菜单新增的规则使用完整路径。
- **损坏配置不降级为空**：读取或校验失败会停止操作并指出问题，原文件保留。
- **日志轮转**：最多保留当前日志及 3 个备份，每个约 1 MB。

## 使用

1. 启动工具，在干净办公环境下点击“捕获基线”。首次捕获前不能进入游戏模式。
2. 在“排除名单（保留运行）”中刷新列表，选择需要保留的语音、直播或其他程序。
3. 点击“进入游戏模式（正常关闭并保存记录）”。如果目标软件要求保存，请处理它自己的提示。尚未关闭的应用不会被强杀。
4. 游戏结束后点击“恢复应用”。未确认的项会保留，必要时手动检查应用并选择重新尝试。
5. 不需要恢复时选择“放弃恢复 / 返回就绪”。“开机自启”使用当前程序所在路径；移动程序后需重新设置。

蓝色图标表示就绪；红色表示游戏模式或有操作待处理。提示文字会区分游戏模式、部分操作待处理和上次未完成的操作。没有待恢复应用时也可以明确退出游戏模式。

## 恢复范围

恢复记录不是进程内存或文档内容备份。工具不能保证未保存内容、所有浏览器标签或同一进程内的多个工作区完整恢复；这些能力依赖目标软件自身的会话恢复设置。

程序没有可见窗口、启动非常慢、需要额外确认、使用内部辅助进程参数或原工作目录已不存在时，恢复可能无法确认。此时记录会保留。正常关闭窗口后，应用也可能按自己的设置继续后台运行。

旧版本的列表式快照可读取；新版本会在下一次状态提交时写入版本 2 格式。升级后不要再用旧版读写新快照。配置和记录位于 %APPDATA%\GameSwitcher，编辑前先安全退出工具。

配置示例：

~~~json
{
  "exclude_list": ["C:/Apps/Voice/voice.exe"],
  "grace_timeout_sec": 5,
  "restore_timeout_sec": 8
}
~~~

关闭等待范围为 0.1–60 秒，恢复确认范围为 1–30 秒。旧配置中的文件名排除规则仍有效，会保留所有同名程序；新菜单采用路径规则。

## 运行、测试与构建

推荐 Windows、Python 3.13，依赖固定为已验证版本。

~~~powershell
python -m pip install -r requirements.txt
python main.py

# 隔离安全回归：不会关闭或启动真实应用
python -m unittest discover -s tests -v

# 原生隐藏托盘自检：临时配置，不操作应用或注册表
python main.py --self-test

# 构建
python -m pip install -r requirements-build.txt
python -m PyInstaller GameSwitcher.spec --noconfirm

# 发布制品自检；输出结果到指定 JSON
.\dist\GameSwitcher.exe --self-test packaged-smoke.json
~~~

GitHub Actions 会在 Windows 上执行回归、源码原生自检、构建和 EXE 自检。历史下载位于 [Releases](https://github.com/jokerD888/GameSwitcher/releases)；本地修复不等于已上传新版发布包。
