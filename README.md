## 🚀 快速上手（仅需 3 步）

1. **放置运行**：下载 `GameSwitcher.exe` 放置于任意目录，双击运行，常驻右下角托盘。
2. **捕获基线**：在刚开机的干净环境下（仅运行输入法、杀软、系统守护等必要后台），右键托盘图标 → **「捕获基线」**。只需操作一次。
3. **日常畅玩**：
   - **打游戏前**：右键托盘图标，根据需要选择：
     - **「🚀 进入游戏（保留现场 · 推荐）」** —— 工作现场全保留，毫秒级解冻！
     - **「🧹 彻底清场（极度纯净 · 关机首选）」** —— 显存内存全清空，关机首选！
   - **打完游戏**：右键托盘图标 → **「✨ 恢复应用」**，一秒满血回归！
   - **打完想睡觉**：右键托盘图标 → **「🗑️ 放弃恢复 / 返回就绪」**，直接清空状态关机睡觉。

## 🛡️ 智能排除名单（永不处理）

不想在游戏过程中受影响的软件（如开黑语音 YY、Discord、加速器、直播推流 OBS 等）：
- 右键托盘图标 → **「排除名单（保留运行）」**：
  - 菜单直接列出当前所有正在运行的可见软件，**点一下直接加入排除名单**，无需手动敲文件名。
  - 顶部标有 `✓` 的为已排除项目，点击可随时取消。

## 💡 为什么说它是最克制的极客工具？

1. **防幽灵窗口机制（No Ghost Windows）**：休眠模式在挂起前自动调用 `ShowWindowAsync(SW_HIDE)` 隐藏顶层窗口，彻底杜绝 DWM 判定“未响应”和白屏卡顿。
2. **多进程树完整覆盖**：对于 Chrome、Edge、VS Code 等拥有数十个子进程的现代软件，递归扫描整棵进程树并原子操作，杜绝后台子进程偷跑。
3. **退出安全收尾**：若退出 GameSwitcher，会自动解冻所有挂起中的应用并重现窗口，绝不遗留孤儿挂起进程。
4. **极低资源消耗**：单文件仅 **~7.8 MB**，开机常驻内存仅 **~6.7 MB**，CPU 占用 0%。
