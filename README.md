# GameSwitcher — 极速游戏模式一键切换伴侣

> 打游戏前一秒清空非基线后台，打完游戏一键还原工作现场。纯静默、零弹窗打扰、极致轻量。

电脑开着一堆浏览器、IDE、微信、钉钉、播放器、办公套件，想打 3A 大作或电竞网游时不仅吃满 CPU/显存/内存带宽，还经常弹窗掉帧。打完游戏一个个找回打开又耗时费力。  
**GameSwitcher** 为此而生——右键托盘两下点击，极速完成游戏与办公环境无缝切换。

---

## 🌟 核心特性

- ⚡ **极致极速关闭**：并发广播 `WM_CLOSE` 优雅保存信号 + 1.5 秒缓冲平滑退离 + 单次批量 `TASKKILL` 瞬间清场，**体感 1 秒完成，0 弹窗打扰**。
- 🎯 **清晰红蓝状态心智**：
  - 🔵 **天蓝徽标**：正常就绪状态。
  - 🔴 **电竞炽红**：游戏模式中（托盘悬浮文字实时显示已挂起应用数量）。
- 🔕 **静默哲学 (Rule of Silence)**：成功操作绝不弹窗打扰；必要气泡提示 3 秒自动精准撤回，绝不遮挡游戏视野。
- 🛡️ **智能免输排除名单**：右键菜单直接罗列当前运行的软件，点击即可一键加入或移出排除名单，无需手动敲文件名。
- 🔄 **断电级安全快照**：快照持久化保存在本地；游戏过程中即使电脑关机或崩溃，重启后挂起应用依然完好无损，随时可恢复。
- 🗑️ **灵活的放弃恢复**：打完游戏太晚只想直接关机睡觉？支持一键「放弃恢复（清空挂起快照）」，不重新拉起旧软件并立刻重置为就绪状态。
- 🪶 **极致羽量级**：单文件仅 **~7.58 MB**，开机常驻内存仅 **~6.7 MB**，CPU 占用 0%，零后台损耗。

## 🚀 快速上手（仅需 3 步）

1. **放置运行**：将 `GameSwitcher.exe` 放置于固定文件夹（如工具专有目录），双击启动。软件将常驻在屏幕右下角托盘区。
2. **捕获基线**：在刚开机的干净环境下（仅运行输入法、杀软、系统守护等必要后台），右键托盘图标 → **「捕获基线（以此为准保留应用）」**。这一步只需操作一次。
3. **开机自启**：右键托盘图标 → 勾选 **「开机自启」**，开机自动待命。

## 🎮 日常使用流程

* **打游戏前**：右键托盘图标 → **「🎮 进入游戏模式（关闭并保存快照）」**  
  *工具将拍照记录当前打开的应用并极速关闭它们，托盘图标切换为高亮电竞红。*
* **游戏中**：全身心畅玩，后台纯净零干扰。
* **打完游戏**：
  * **想继续工作**：右键托盘图标 → **「✨ 恢复应用 (X 个已保存)」**，一键拉起之前的所有软件。
  * **想关机睡觉**：右键托盘图标 → **「🗑️ 放弃恢复（清空挂起快照）」**，直接清空快照恢复天蓝就绪状态。

## 🛡️ 排除名单（永不关闭）

不想在游戏模式中关闭某些应用（如语音软件 Discord/YY、加速器、直播推流 OBS 等）：
* 右键托盘图标 → **「排除名单（永不关闭）」**：
  * 菜单底部列出了当前正在运行的可见应用，**点击对应软件名称即可秒级加入排除名单**。
  * 菜单顶部标有 `✓` 的为已排除软件，点击即可取消排除。
  * 支持点击 **「📁 打开配置与日志目录」** 直接查看/编辑 `config.json`。

## 💡 常见问题 (FAQ)

**Q：进入游戏模式时会有打扰弹窗吗？**  
A：**完全没有。** 遵循极客静默哲学，关闭和恢复成功均不弹窗。工具会先给应用发送关闭消息让其自动保存状态，并在 1.5 秒后批量强杀残留；仅当存在权限受限等异常无法杀死的进程时，才会弹窗提示。

**Q：恢复之后，浏览器的多标签页能找回来吗？**  
A：能。大多数现代浏览器（Chrome、Edge、Brave 等）和开发工具（VS Code、Sublime）原生支持崩溃与重启恢复会话，拉起后自动恢复上次打开的所有标签页。

**Q：哪些程序绝对不会被误杀？**  
A：已捕获的基线应用、排除名单中的应用，以及 Windows 核心系统界面（Explorer 资源管理器、输入法、dwm 窗口管理器、显卡驱动覆盖层、Xbox GameBar 等）。

**Q：占电脑配置资源吗？**  
A：单文件仅 **7.58 MB**，后台常驻运行时 CPU 占用为 0%，物理内存占用通常不足 7 MB，完全可以忽略不计。

**Q：如何完全卸载？**  
A：右键托盘取消「开机自启」→ 点击「退出」→ 删除 exe 文件及 `%APPDATA%\GameSwitcher\` 目录即可。绿色纯净无残留。

## 🛠️ 技术栈与编译构建

- **核心语言**：Python 3.13（纯 Win32 API 交互 + psutil 进程树并发解析 + pystray 极简托盘）
- **性能优化**：懒加载进程信息、单次系统遍历构建哈希索引、Windows 原生多 PID 批量 Taskkill
- **打包配置**：基于 `GameSwitcher.spec`，深度剥离 NumPy、未使用编解码器与冗余标准库，实现包体与内存双极致

```bash
# 安装开发依赖
pip install -r requirements.txt

# 运行源码
python main.py

# 重新构建单文件便携可执行程序
python -m PyInstaller GameSwitcher.spec --noconfirm
```
